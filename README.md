# Nikil S Kumar — Portfolio

Personal portfolio site built with Next.js, React, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev:clean
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Edit content

| File | Purpose |
|------|---------|
| `data/profileData.js` | Name, title, links, resume |
| `data/aboutPageData.js` | About page copy |
| `data/projectsData.js` | Projects |
| `data/clientsData.js` | Companies worked with |
